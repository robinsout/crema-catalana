# Адаптация урока на другой язык

Аргументы: id урока (или `all` — все ещё не адаптированные/устаревшие) и код языка. Новый урок к юниту сразу на всех языках группы пишет `/lesson` (он сам запускает адаптации); `/adapt` — для отдельного урока, нового языка или устаревшей адаптации. Урок **адаптируется, а не переводится**: объяснения и сравнения пишутся под родной язык ученика по его профилю. Каталанские примеры общие для всех языков.

## 0. Язык
- Языка ещё нет (`content/locales/<код>/` нет) → `npm run new-language -- <код> <Название на нём самом>`. Язык появится **черновиком** (`drafts` в `locales/index.json`): тесты его проверяют, сайт открывает его по прямой ссылке `#/<код>/plan`, но в переключателе его нет.
- Профиль `authoring/profiles/<код>.md` — заполни **до первого урока**: кто ученик, что легко, что трудно, ложные друзья, с чем сравнивать, термины. Сравни с `authoring/profiles/ru.md`. Профиль покажи пользователю, прежде чем адаптировать много уроков.
- Переведи `content/locales/<код>/ui.json` (все ключи; `_dateLocale` — локаль дат) и `catalog.json` (тексты плана; без `date` — её ставит адаптация).

## 1. Что адаптировать
```
npm run coverage        # ✅ готово · ⚠️ устарело · — нет
```
Новая адаптация: `npm run adapt -- <id> <код>` — копирует урок с отпечатком исходника (`<!-- source: ru@… -->`, не удалять), упражнения, перевод словаря и тексты плана, ставит дату.
Устаревшая (⚠️): посмотри, что изменилось в исходнике (`git log -p content/locales/ru/lessons/<id>.html`), перенеси изменения, затем `npm run adapt -- <id> <код> --restamp`.

## 2. Переписать под ученика
Файлы: `content/locales/<код>/lessons/<id>.html`, `exercises/<id>.json`, `vocab/<id>.json`, `catalog.json` → `lessons.<id>`.
- **Нельзя менять** (тесты): id и порядок глав `<section id>`, id упражнений `data-exercise` — на них хранится прогресс, общий для всех языков.
- **Каталанское** (`lang="ca"`, ответы упражнений, слова словаря) — по возможности те же фразы: озвучка переиспользуется. Можно добавить или убрать примеры, если этого требует сравнение с родным языком ученика.
- **Объяснения** — заново по профилю: англоговорящему не опираться на испанский (род, артикли, спряжение объяснять), испаноговорящему — кастильянизмы и произношение, италоговорящему — `ne/ci ≈ en/hi`, passato prossimo против `vaig + infinitiu`.
- Заголовки глав, подсказки (`hint`), пояснения (`explain`), подписи схем и таблиц — на языке ученика. Русского текста не остаётся: тест ищет кириллицу.

## 3. Рецензия, озвучка и проверка
`/review-lesson <id>` — независимый рецензент читает адаптацию (каталанский, язык объяснений, профиль, ошибки смысла); проверь находки и примени верные.

```
npm run audio
npm run check
npm run look -- '#/<код>/lesson/<id>'
```
Прочитай снимки из `test-results/look/`.

## 4. Выпуск языка
Когда у языка готовы интерфейс, план и хотя бы вводный урок (`intro`), и пользователь согласен: `npm run publish-language -- <код>` (откажет, если в интерфейсе или плане остался русский текст). Для `en` заодно `default` → `en` в `locales/index.json` (язык для неподдерживаемых браузеров).

## 5. Коммит и итог
Коммит на каждый урок или пачку уроков. Итог пользователю: что адаптировано, что в объяснениях сделано иначе, чем в исходнике, и почему; что осталось (`npm run coverage`).
