# Урок на всех языках группы

Аргумент — id юнита (`b1-04`) или тема нового урока. Порталом пользуются одногруппники (англо- и испаноговорящие, большинство — латиноамериканцы), поэтому урок выходит **сразу на всех опубликованных языках** (`available` в `content/locales/index.json`), а не на одном русском. Базовый язык — `base` (сейчас `ru`): урок пишется на нём, остальные языки — адаптации по профилям учеников (`authoring/profiles/<язык>.md`), не переводы.

Пишем содержание; файлы, регистрацию и проверки делают команды.

## 1. Понять, что за урок
- **Юнит** (`b1-01` … `b3-09`): он уже есть в `content/course.json`; план — `content/locales/<язык>/catalog.json` → `lessons.<id>` (`topic`, `grammar`, `vocab`, `extra`, `mission`). План восстановлен по названиям юнитов и **неточен** (юнит 1: не было родного языка, притяжательных, стран с артиклем). Поэтому:
  - есть фото юнита в `photos-del-libro/` → сконвертируй (`sips -s format jpeg -Z 1800 <файл> --out <scratchpad>/…`) и прочитай: «La ruta pas a pas», активности, ссылки на грамматику;
  - фото нет → попроси пользователя сфотографировать разворот «La ruta pas a pas» и страницы активностей юнита. Не ждёт — пиши по плану и скажи об этом в итоге.
  - Поправь план юнита во **всех** языках каталога. Фото и тексты учебника никуда не копируй: книга под авторским правом, репозиторий публичный (`photos-del-libro/` в `.gitignore`); примеры пишем свои.
- **Тема или обзор**: id `x-<тема-по-каталански>` (вечный), `kind` (`topic` — одна тема, `overview` — общая картина), каталанское название, связанные юниты (`related`).
- Урок **дополняет** учебник, а не пересказывает его: разбирает то, что в материале юнита трудно именно носителю каждого языка группы. Прочитай профили всех языков группы и уже написанные уроки (тон, объём, приёмы); не повторяй старое — ссылайся на него (`#/<язык>/lesson/<id>`).

## 2. Русский урок
```
npm run new-lesson -- b1-04
npm run new-lesson -- x-pronoms-febles --kind topic --title "Els pronoms febles" --related b2-03,b2-04
```
Файл `content/locales/ru/lessons/<id>.html` — HTML-фрагмент, не Vue. Правила из `CLAUDE.md` («Как добавить урок») обязательны; главное:
- **Главы** — `<section id="…"><h2>N. Название</h2>`. Id главы — короткое каталанское слово (`hora`, `possessius`), **вечное**: на нём хранится прогресс; добавлять главы можно, удалять и переименовывать нельзя. Подзаголовки `<h3>N.M …</h3>`. Последняя глава — «Практика»; в уроке к юниту в ней **миссия** из плана (`aside.ru` с меткой).
- **Каталанский текст** — `lang="ca"` (span, td, li, p, blockquote; `<table lang="ca">` озвучивает каждую `td`). Внутри `lang="ca"` — только каталанский; перевод и пояснения снаружи; без вложенных `lang="ca"`. Кастильянизмы — только как ошибки: `<span lang="ca" class="wrong">`.
- Разметка стилей: `.tw > table`, `table.conj`, `aside.tip|warn|ru` с `<p class="label">`, `.ex`, `.ipa`, `.wrong`, `blockquote.reading`, `<details><summary>`, схемы `.tmap`, `ol.story`, `.quarts`, `.daybar`, `.year`.
- Сравнение — по профилю `ru`: испанский, где полезно — французский и русский. Центральный вариант, IEC 2016.
- **Упражнения**: `<div data-exercise="<id>"></div>`, данные — `content/locales/ru/exercises/<урок>.json` (`fill`: `prompt`, `answers` — первый показывается как решение, `hint`; `choice`: `options`, `answer`, `explain`). Свободный перевод — спойлером `<details>`.
- **Словарь**: `"hasVocab": true` в `course.json`, `content/vocab/<id>.json` (каталанские слова с артиклем, род, мн. число — общие для всех языков), `content/locales/ru/vocab/<id>.json` (перевод).
- Тексты плана: у юнита — план (уже поправлен в шаге 1), у темы — `subtitle` во всех языках.

Потом `npm run register` (id урока и глав → `tests/published-*.json`, они вечные).

## 3. Адаптации — параллельно
```
npm run adapt -- <id> en
npm run adapt -- <id> es        # и так для каждого языка группы, кроме ru
```
Затем по одному агенту на язык, **одновременно** (`Agent`, тип `fork`, в фоне). Каждому — задание:
- свои файлы и только они: `content/locales/<язык>/lessons/<id>.html`, `…/exercises/<id>.json`, `…/vocab/<id>.json`; первую строку `<!-- source: … -->` не трогать; общие файлы (`catalog.json`, озвучка, тесты), `npm run audio`, git — не трогать: это делаешь ты;
- прочитать `authoring/profiles/<язык>.md` и `.claude/skills/adapt/SKILL.md`; переписать урок под ученика, сохранив главы (id и порядок) и упражнения (id);
- проверить свои файлы через `scripts/lib/lesson-check.ts` (`lintLesson`, `compareOutlines` с русским уроком, `cyrillicLeftovers`);
- вернуть сводку и список новых каталанских фраз.
Пока агенты работают — посмотри русский урок глазами (`npm run look -- '#/ru/lesson/<id>'`).

## 4. Рецензия
`/review-lesson <id>` — независимые рецензенты по всем языкам. Проверь находки, примени верные. Правка русского урока → перенеси в адаптации и `npm run adapt -- <id> <язык> --restamp`.

## 5. Озвучка, проверки, глазами
```
npm run audio                    # нужен edge-tts (EDGE_TTS=~/Library/Python/3.14/bin/edge-tts)
npm run check
npm run coverage                 # урок ✅ на всех языках группы
npm run look -- '#/ru/lesson/<id>' '#/en/lesson/<id>' '#/es/lesson/<id>'
```
Прочитай снимки из `test-results/look/` (компьютер и телефон, светлая и тёмная тема): таблицы не вылезают, схемы читаются.

## 6. Выкладка
Коммит с понятным описанием (что за урок, что в нём, по каким языкам). Урок нужен одногруппникам, поэтому, если пользователь не просил иначе, — `git push`, затем `gh run watch <id> --exit-status` и проверка, что CI зелёный и сайт задеплоен.

## 7. Итог пользователю
Коротко: главы урока, что взято из учебника и что добавлено сверх него для каждого языка, что нашла рецензия, какие допущения (например, план без фото). Попроси проверить тексты на языках, которые он знает (en, es).
