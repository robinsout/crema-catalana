# Урок на базовом языке

Аргумент — id юнита (`b1-04`) или тема нового урока. Пишем содержание; файлы, регистрацию и проверки делают команды. Базовый язык — `base` в `content/locales/index.json` (сейчас `ru`).

## 1. Понять, что за урок
- **Юнит** (`b1-01` … `b3-09`): он уже есть в `content/course.json`. План юнита — `content/locales/ru/catalog.json` → `lessons.<id>`: `topic`, `grammar`, `vocab`, `extra`, `mission`. План восстановлен по названиям юнитов, поэтому коротко спроси, что реально проходили на занятии (тема, грамматика, слова). Если ответа нет — пиши по плану и скажи об этом в итоге.
- **Тема или обзор**: придумай id `x-<тема-по-каталански>` (вечный), `kind` (`topic` — одна тема, `overview` — общая картина), каталанское название, связанные юниты (`related`).
- Прочитай профиль ученика `authoring/profiles/ru.md`: с чем сравнивать, какие ловушки, какие термины. Посмотри уже написанные уроки (`content/locales/ru/lessons/`): тон, объём, приёмы разметки. Новое не должно повторять старое — ссылайся на него.

## 2. Заготовка
```
npm run new-lesson -- b1-04
npm run new-lesson -- x-pronoms-febles --kind topic --title "Els pronoms febles" --related b2-03,b2-04
```
Создаёт файл урока с двумя главами-примерами, дату и (для темы) запись в `course.json`.

## 3. Текст урока (`content/locales/ru/lessons/<id>.html`)
Урок — HTML-фрагмент, не Vue. Правила из `CLAUDE.md` («Как добавить урок») обязательны; главное:
- **Главы** — `<section id="…"><h2>N. Название</h2>`. Id главы — короткое каталанское слово (`hora`, `practica`), **вечное**: на нём хранится прогресс. Подзаголовки `<h3>N.M …</h3>`. Последняя глава — «Практика»; в уроке к юниту в ней же **миссия** из плана.
- **Каталанский текст** — `lang="ca"` (span, td, li, p, blockquote; `<table lang="ca">` озвучивает каждую `td`). Внутри `lang="ca"` — только каталанский: перевод и пояснения снаружи. Вложенных `lang="ca"` нет. Это проверяет тест.
- Разметка, которую понимают стили: `.tw > table`, `table.conj`, `aside.tip|warn|ru` с `<p class="label">`, `.ex`, `.ipa`, `.wrong`, `blockquote.reading`, `<details><summary>`, схемы `.tmap`, `ol.story`, `.quarts`, `.daybar`, `.year`.
- Сравнение — по профилю: в первую очередь с испанским, где полезно — с французским и русским. Центральный вариант, орфография IEC 2016.
- **Упражнения**: `<div data-exercise="<id>"></div>` в тексте, данные — `content/locales/ru/exercises/<урок>.json` (`fill`: `prompt`, `answers` — первый ответ показывается как решение, `hint`; `choice`: `options`, `answer`, `explain`). Свободный перевод — спойлером `<details>`.
- **Словарь** (если в уроке есть лексика): `"hasVocab": true` в `course.json`, `content/vocab/<id>.json` (каталанские слова с артиклем, род, мн. число), `content/locales/ru/vocab/<id>.json` (перевод, примечания).
- Тексты плана в `catalog.json`: у юнита план уже есть (поправь, если на занятии было иначе), у темы — `subtitle`.

## 4. Озвучка, регистрация, проверка
```
npm run audio      # новые каталанские фразы; нужен edge-tts
npm run register   # id урока и глав → tests/published-*.json (они вечные)
npm run check
```
Ошибки тестов говорят, что поправить: фраза без озвучки, кириллица внутри `lang="ca"`, упражнение без данных, глава без заголовка.

## 5. Посмотреть глазами
```
npm run look -- '#/ru/lesson/<id>'
```
Прочитай снимки из `test-results/look/` (компьютер и телефон, светлая и тёмная тема): таблицы не вылезают, схемы читаются. Длинные таблицы на телефоне — в `.tw`.

## 6. Закоммитить
Коммит с понятным описанием (что за урок, что в нём). Пушить — по просьбе пользователя или в `/close-session`.

## 7. Итог пользователю
Коротко: что в уроке (главы), что из плана юнита взято и что поправлено, какие допущения. Если урок есть на других языках (правка существующего) — `npm run coverage` покажет ⚠️: адаптации устарели, предложи `/adapt`.
