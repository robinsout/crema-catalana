# Рецензия урока

Тесты проверяют структуру (главы, упражнения, озвучка, кириллица, разметка), но не смысл. Ошибки смысла находит только чтение: «как в испанском» там, где должно быть «в отличие от испанского», неверный род слова, испанизм Испании в тексте для латиноамериканцев, кастильянизм в каталанском примере. Поэтому после написания урока его читает **агент, который его не писал**: свежий контекст не повторяет ошибок автора.

## 1. Что рецензировать
Аргумент — id урока. Языки — все, где урок написан (`npm run coverage`): базовый `ru` и адаптации. Если менялся только один язык, рецензируй его и базовый (для сверки).

## 2. Запуск рецензентов
По одному агенту на язык, **параллельно**, тип `general-purpose` (не `fork`: рецензенту нужен свежий взгляд, а не контекст автора). Каждому — задание ниже с подставленными `<id>`, `<lang>`. Рецензенты **ничего не правят**, только отчитываются.

```
Ты рецензент учебного портала каталанского языка Quadern de català (репозиторий в текущей папке).
Проверь урок <id> на языке <lang>. Файлы: content/locales/<lang>/lessons/<id>.html,
content/locales/<lang>/exercises/<id>.json, content/locales/<lang>/vocab/<id>.json (если есть),
content/vocab/<id>.json (каталанские слова), content/locales/<lang>/catalog.json → lessons.<id>.
Для сверки: русский исходник content/locales/ru/lessons/<id>.html.
Профиль ученика: authoring/profiles/<lang>.md — урок должен ему соответствовать.
Ничего не меняй в файлах. Верни список находок, самые серьёзные первыми; для каждой:
место (глава/строка, цитата), что не так, как исправить.

Проверь:
1. Каталанский: центральный (барселонский) вариант, орфография IEC 2016 (soc, dona, vens; 15 диакритик),
   род и число, формы глаголов, апострофы и слияния (del, de l'), нет кастильянизмов в правильных примерах
   (кастильянизмы допустимы только как ошибки с class="wrong"). Примеры естественны, так говорят.
2. Объяснения верны по сути: правило сформулировано правильно, сравнения с родным языком ученика не
   перевёрнуты («как в X» против «в отличие от X»), примеры иллюстрируют то, что заявлено, перевод
   каталанских фраз точный.
3. Язык объяснений естественный и единообразный (термины — как в профиле); для es — нейтральный испанский
   для латиноамериканцев (без vosotros и слов только Испании, где слова разные — оба варианта); для en —
   британская орфография.
4. Профиль: опора на родной язык ученика, его ловушки учтены, нет сравнений, рассчитанных на другого
   ученика (например, русских — в английском уроке).
5. Упражнения: ответы правильные и единственные (или все варианты перечислены в answers), подсказки
   помогают, explain верен.
6. Разметка смысла: перевод и пояснения не внутри lang="ca"; ссылки на другие уроки ведут на этот же
   язык (#/<lang>/lesson/…).
Не придирайся к стилю, если смысл и язык в порядке. Если всё хорошо — так и скажи.
```

## 3. Разбор находок
- Каждую находку проверь сам: рецензент тоже ошибается. Примени верные, отклонённые коротко объясни в итоге.
- Правка базового `ru` урока меняет отпечаток исходника: адаптации станут ⚠️ (`npm run coverage`). Перенеси правку в адаптации, затем `npm run adapt -- <id> <lang> --restamp`.
- После правок: `npm run audio` (если менялись каталанские фразы) и `npm run check`.

## 4. Итог
Пользователю — коротко: сколько находок по каждому языку, что исправлено, что отклонено и почему.
